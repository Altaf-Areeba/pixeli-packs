# Pixeli picture packs

Pictures in this repo appear in the Pixeli app **without an app update** (the app checks every 6 hours).

## Add pictures (from phone or computer)
1. Open this repo on github.com → folder **inbox** → **Add file → Upload files**.
2. Upload .png / .jpg / .webp / .svg images. File name = picture name:
   - `red-fox.png` → "Red Fox"
   - `red-fox__rotfuchs__renard-roux.png` → English / German / French names
   - add `@24` or `@48` for size, e.g. `owl@48.png` (default 32)
3. Press **Commit changes**. After ~2 minutes the robot (Actions tab) converts them into `pack-YYYY-MM.json`.

## Rules
- Only your own pictures, AI pictures you are allowed to use, or free-licence images (e.g. CC0). Never copy other games or brands.
- Simple pictures with big shapes and a plain background look best.
